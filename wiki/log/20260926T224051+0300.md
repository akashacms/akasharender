# 2026-09-26 22:40 - Fix link checker misclassifying http://example.com as internal; minimatch ESM test fix

The link checker reported outbound `http://example.com/` links in
`../akashacms-example/documents/markdown.html.md` as
`internal link not found (/http:/example.com/)`.  Root cause: `classify()`
in `lib/link-checker.ts` detected local links with the sentinel-origin trick
(`new URL(href, 'http://example.com')` + origin comparison), and a real
outbound link to that exact origin collides with the sentinel; the href then
flowed into `resolveVpath()`, whose `path.join` collapsed `//` to `/`.

## Changes

- `lib/link-checker.ts`: added exported `hasUrlScheme()`
  (`/^[a-zA-Z][a-zA-Z0-9+.-]*:/`); `classify()` now tests for a leading URI
  scheme **before** the sentinel comparison — scheme-absolute `http(s)` hrefs
  are external, other schemes are other-scheme, protocol-relative `//host`
  hrefs are external, and only scheme-free relative references reach the
  local/`resolveVpath` branch.
- `lib/built-in.ts`: `AnchorCleanup.process()` returns `"ok"` early for
  scheme-absolute or protocol-relative hrefs, avoiding the same collision.
- `lib/index.ts`: re-exported `hasUrlScheme`.
- `test/test-link-checker.mjs`: regression tests for the sentinel-origin
  link, protocol-relative URLs, and colons in non-first path segments.
- `test/test-cache.mjs`: pre-existing failure — `import minimatch from
  'minimatch'` fails under minimatch v10 (pure ESM); changed to the named
  import `{ minimatch }`.

## Verification

- Full test suite green: 408 tests, 0 failures
  (142 + 67 + 131 + 7 + 24 + 19 + 15 + 3 across all suites).
- Rebuilt `dist/` and copied it into
  `../akashacms-example/node_modules/akasharender/dist/`, then re-rendered
  the example site: zero `/http:/example.com/` warnings; the three
  `http://example.com/` anchors render unchanged.  The only remaining
  link-check warning is a genuinely missing file
  (`/vendor/img/adobe-Test.pdf` referenced by
  `viewer-js-viewer/pdf-spec-link.html`).
