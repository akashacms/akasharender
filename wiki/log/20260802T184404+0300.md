# 2026-08-02 18:44 - Add csv-table custom element implementation guide

Created an implementation-design wiki page discussing how to implement the
`<csv-table file-name="..." template="..."/>` custom tag requested in GitHub
issue #85. The page was written to serve as the discussion document for the
feature before any source code is written.

The design is grounded in the existing Built-in Plugin custom-element machinery:
`CodeEmbed` (`lib/built-in.ts`:577-649) is identified as the reference pattern
(it already reads a `file-name` attribute, resolves it via the documents cache,
and reads the file), and `FigureImage`/`InsertTeaser` demonstrate the
`this.akasha.partial(config, template, data)` rendering call. The guide specifies
a tag with `file-name`, `template`, optional `before-template`/`after-template`,
and `format`/`delimiter`/`header` attributes; a normalized row-object data model
(`fields`/`columns`/`index`/`rowNumber`) shared across CSV, TSV, and YAML; a pure
`lib/csv-table.ts` parser helper (delimited via a real CSV parser such as
`csv-parse/sync`, YAML via the already-present `js-yaml` dependency); default
`<table>`/`</table>` partials; escaping guidance; a full test plan; a phased
implementation order; and gotchas.

Registered the new page in `wiki/implementation/README.md` and surfaced it from
the master `wiki/index.md` Implementation list, and refreshed the index
`last-updated` timestamp.
