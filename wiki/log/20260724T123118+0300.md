# 2026-07-24 12:31 - Add memory system to the wiki

Introduced a **memory system** under `wiki/memory/` so that LLMs and LLM Agents
can record and later retrieve durable, reusable knowledge about writing and
debugging code in this project (debugging techniques, build/test/environment
quirks, recurring pitfalls and fixes, working recipes, and subsystem-interaction
insights).

## Changes

- Created `wiki/memory/` with an index `README.md` that explains the purpose of
  memory pages, how to use and find them, and provides both an alphabetical
  index list and a "By Category" list for discoverability.
- Created a seed memory page,
  `wiki/memory/debugging-rendering-pipeline.md`, demonstrating the memory page
  format, the extra `Symptoms`/`Keywords` search frontmatter, and the required
  sections (Context, Technique, Pitfalls, Sources, Related Pages, Backlinks).
- Updated `wiki/AGENTS.md`:
  - Added `wiki/memory/` to the directory structure description.
  - Added `memory` to the allowed `type` frontmatter values.
  - Added a "Memory pages" entry to the Required Sections by Page Type,
    including the `Symptoms` and `Keywords` frontmatter fields.
  - Added a "Memory Workflow" describing when and how to create, find, and use
    memory pages.
  - Extended the Lint Workflow and the navigation-helper-pages workflow to
    cover `wiki/memory/README.md` and its "By Category" list.
- Updated `wiki/index.md` to add a Memory section linking to the memory index
  and the seed page, and refreshed `last-updated`.
- Updated the top-level `AGENTS.md` with a "Memory System" subsection under the
  Wiki Directory section, instructing agents to create memory when they learn
  something reusable and to consult memory before working.
