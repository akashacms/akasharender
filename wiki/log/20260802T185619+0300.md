# 2026-08-02 18:56 - csv-table guide - resolve relative external paths against config.configDir

Settled the previously-open design decision in the `<csv-table>` implementation
guide about where relative *external* data-file paths resolve. Per maintainer
direction, relative external paths now resolve against `config.configDir` — the
directory containing the project's configuration file — rather than a new
configurable data-root option.

This is consistent with existing AkashaRender behavior: `config.configDir` is set
to `path.dirname(modulepath)` (`lib/index.ts`:735), exposed via a public
getter/setter (`lib/index.ts`:878-879), and already used as the anchor for
relative `assetsDirs`/`documentsDirs`/`layoutsDirs`/`partialsDirs`
(`lib/index.ts`:908-910). A `file-name` like `../data/people.csv` therefore
reaches a sibling of the project without hard-coding an absolute path.

Updated the "File resolution" section (replacing the open "where do relative
external paths resolve" decision with the settled rule), the resolution pseudocode
and the `resolveDataFile` helper (using `path.resolve(config.configDir, fn)`), the
file-resolution test case, the gotchas, and the `lib/index.ts` source description.
Refreshed the page `last-updated` timestamp.
