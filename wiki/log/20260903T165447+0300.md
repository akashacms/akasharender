# 2026-09-03 16:54 - Implementation plan for removing legacy render functions and watchman references

Created an implementation guide for the house-cleaning refactor requested by
the project leader: remove the non-"2" render functions, transition all
callers to the "2" versions, rename the "2" functions to the base names, and
purge stale references to the long-deleted `lib/watchman.ts`.

Key facts verified during research:

- Production (CLI, sibling site projects) uses only `render2`,
  `renderDocument2`, `renderPath2`.
- Only in-repo callers of the legacy API are `test/index.mjs:106`,
  `test/rebased.mjs:103`, `test/test-relative.mjs:106`.
- External caller exists: `../akasharender-epub/rendercli.js:51` calls
  `akasha.render()`; the epub plugin is already out of sync with HEAD (calls
  non-existent `cacheSetupComplete`).
- `module_exports` in `lib/index.ts` omits `renderDocument2` while exporting
  the legacy names — to be fixed during the rename.
- No watchman references in `lib/` or `package.json`; remaining references
  are in repo-root docs, several wiki pages, and (immutable) logs.
