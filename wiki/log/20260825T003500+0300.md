# 2026-08-25 00:35 - Add answer page on running code after regular Mahabhuta processing (final mahafuncs)

The user asked how to execute Mahabhuta processing after all regular Mahabhuta processing is finished but before the Cheerio structures are rendered back to HTML. The referenced how-to page (`../akashacms-website/documents/howto/final-post-processing.html.md`) describes an `akasha.emitter.on('file-rendered', ...)` API that does not exist anywhere in the source. Investigation showed the real mechanism is Mahabhuta's **final mahafuncs**: `MahafuncArray` runs a second list of functions (`final_functions`, added via `addFinalMahafunc()`) after all regular functions and before `processAsync()` serializes the DOM with `$.html()`. The Built-in Plugin already uses this pattern (`MungedAttrRemover`, `BlankLinkDefanger`), and `test/final-mahabhuta.js` provides a working fixture. A new answer page records the finding, the usage recipe, caveats, and a note that the akashacms-website how-to page needs updating.
