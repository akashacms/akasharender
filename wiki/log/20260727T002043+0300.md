# 2026-07-27 00:20 - Add breadcrumb trail schema.org markup architecture document

Created a new architecture document describing the structured-data (web-schema) markup used for the breadcrumb trail produced by the `@akashacms/plugins-breadcrumbs` plugin.

The document records the decision to emit schema.org `BreadcrumbList` as **inline microdata** on the existing breadcrumb links, and explains why this was chosen over the previous (incorrect) `p-category` microformats2 class.

It fully documents the **JSON-LD** alternative — including an example `BreadcrumbList` JSON-LD block — and records that JSON-LD has **not** been implemented. The main reason captured is that JSON-LD `BreadcrumbList` markup requires **absolute URLs**, whereas AkashaCMS projects are rendered for **relative URLs**; the microdata approach works with relative URLs because the crumb's own `href` serves as `itemprop="item"`. The document also outlines what a future opt-in JSON-LD implementation would require, referencing the absolute-URL construction pattern already used by the sitemap generator.
