# 2026-09-03 17:12 - Phase 1 executed - tests transitioned to render2; epub deferred

Executed Phase 1 of the legacy-render-functions removal plan, scoped to this
package only. The akasharender-epub transition is deferred to GitHub issue
akashacms/akasharender#212 per the project leader.

## Analysis

- Switching the three test suites to `render2` initially failed the
  image-resize tests (`900 == 50`): `copyAssets()` re-copies original images
  over previously resized in-place files, and documents skipped by
  `isDocumentUpToDate` never run Mahabhuta, so the resize queue is never
  populated. Verified pre-change code passed (stash run: 67/67).
- Fix: pass `{ forceRenderAll: true }` to `render2`, the exact equivalent of
  legacy unconditional rendering.
- `test-incremental.mjs` Scenario 4 is a flaky wall-clock timing assertion
  under full-suite load; passes reliably in isolation. Not related to the
  change.

## Changes

- test/index.mjs, test/rebased.mjs, test/test-relative.mjs:
  `akasha.render(...)` → `akasha.render2(..., { forceRenderAll: true })`;
