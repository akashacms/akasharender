# 2026-08-13 23:55 - Add Vendor Library Plugins architecture page

Added a new architecture page documenting the repeatable pattern for building
AkashaCMS plugins that wrap 3rd-party JavaScript / CSS / image (SVG) libraries.
The content was originally drafted as `ARCHITECTURE-vendor-library-plugins.md`
in the repository root; it has been rewritten to the wiki architecture-page
format (frontmatter, `## Query` / `## Architecture` / `## Sources` /
`## Related Pages` / `## Backlinks` sections, relative Markdown links) and moved
into `wiki/architecture/`. The misplaced root-level file was deleted.

The page draws on the four existing vendor-library plugins
(`@akashacms/bootstrap-icons`, `@akashacms/country-flag-icons`,
`@akashacms/tabler-icons`, `@akashacms/theme-bootstrap`) and the AkashaRender
`Configuration` / `Plugin` / `VFStack` source, and gives a step-by-step recipe
for wrapping future libraries.
