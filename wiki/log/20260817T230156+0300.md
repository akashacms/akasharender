# 2026-08-17 23:01 - Add "How the AkashaCMS Page Rendering Process Works" answer page

In response to the user question "How does the AkashaCMS page rendering process
work?", created a new answer page giving a high-level overview of the rendering
process. It frames the process as a site-wide loop (`render`/`render2`) wrapping
the per-document three-stage pipeline, complementing the existing detailed
single-page walkthrough in `rendering-flow-from-vpath.md` rather than duplicating
it.

The content was synthesized from the wiki (`three-stage-rendering.md`,
`rendering-flow-from-vpath.md`, `site-rendering.md`, `rendering-pipeline.md`) and
verified against `lib/render.ts`. All four concept pages cross-linked from
`three-stage-rendering.md` (`rendering-pipeline.md`, `mahabhuta-system.md`,
`layout-templates.md`, `template-rendering.md`) were confirmed to exist.
